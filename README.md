# To-Do List Kelompok

## Deskripsi Proyek
To-Do List merupakan aplikasi berbasis web sederhana yang digunakan untuk membantu pengguna mencatat, mengelola, dan memantau daftar tugas atau pekerjaan sehari-hari.

## Tujuan
Membuat aplikasi pengelolaan tugas sederhana agar pengguna dapat mencatat tugas dan mengetahui jumlah tugas yang dikelola.

## Fitur Aplikasi
1. Menambahkan tugas baru.
2. Menampilkan daftar tugas.
3. Menghapus tugas.
4. Menghitung jumlah tugas.

## Teknologi yang Digunakan
- HTML
- CSS
- JavaScript
- Git dan GitHub

## Struktur File
- `index.html` : Struktur halaman aplikasi.
- `style.css` : Mengatur tampilan aplikasi.
- `script.js` : Mengelola fungsi utama aplikasi.
- `hapus.js` : Mengelola fungsi penghapusan tugas.
- `hitung.js` : Menghitung jumlah tugas.

1. Clone repository ke komputer.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Buka file `index.html` menggunakan browser.
4. Jalankan dan uji fitur aplikasi.
